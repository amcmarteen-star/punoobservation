Reference Dataset

Import official DENR NGP contract-profile Excel files. Matches sites by Site Code -- re-uploading the same file safely updates existing records instead of duplicating them.

Upload DENR NGP Excel File

Accepted sheets: 2021, 2022, 2023, Retention Fee. Other sheets in the file (e.g. Summary) are ignored automatically.

What Gets Imported

  • Site Code, Zone Type, LOA/Contract Code, Year Contracted
  • Area Contracted (ha) and Actual Area Planted (ha)
  • Contract execution & expiry dates
  • Project cost, retention fee amount & date paid, land improvement amounts
  • Number of seedlings (target vs actually planted), survival rate, validation date
  • Municipality & Barangay -- auto-created in Location table if not already there
  • Partner/Contractor -- auto-created in Organization table if not already there

Note: tree species matching is not built yet -- imported reforestation records are tagged "Unspecified (Pending Match)" for now and can be updated once that feature is ready.
