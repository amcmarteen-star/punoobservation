{# FAQ for Reference Dataset (admin.reference_dataset). System administrators only. Behaviour described lives in admin.preview_denr_data and admin.import_denr_data. #}
What file can I upload?

An official DENR NGP contract-profile Excel file (.xlsx or .xls), up to 10 MB.

Sheets 2021, 2022, 2023 and Retention Fee are read. Other sheets, such as Summary, are skipped.

Will uploading the same file twice make duplicates?

No. Sites are matched by Site Code, so existing sites are updated instead of copied.

That is why site codes must never be changed in the file.

What does Preview do?

It reads the file and shows what would change, without saving anything. Use it to catch wrong rows before you import.

What gets imported?

Site details, areas, contract dates, costs, seedling targets and numbers planted, survival rates, and validation dates.

New municipalities, barangays and partner organisations are added if they are not there yet.

Why do imported sites say "Unspecified (Pending Match)" for species?

Matching tree species from the file is not built yet. Every imported record gets this placeholder until it is.

Where can I see past imports?

Under Recent imports on this page, or in the Audit Log.
