Checking the request

What should I check?
  • The pin and drawn area are on the right land.
  • The land ownership makes sense for planting.
  • The attached documents, such as an Indicative Management Plan.
  • Other sites and requests in the same barangay, shown under Context.
Why is the drawn area partly outside the barangay outline?

Barangay outlines are approximate. A few corners just outside are usually fine. The pin itself must be inside the barangay, or the request would not have been accepted.

How was "Estimated seedlings" worked out?

Area ÷ spacing for the planting type the requester chose. It has no allowance for replanting.

What are the recommended species for?

Guidance on what would grow well in this barangay. Use it when you discuss the planting with the requester.

Deciding

What happens when I approve?

The requester is notified. Approving does not create a site by itself.

For a New Planting Site request, press Create site from this request next. Field officers can monitor the site once it exists.

Why can't I create a site from this request?

A site can only be created when:

  • the request is Approved,
  • its type is New Planting Site, and
  • no site was created from it already.
Why can't I un-approve this request?

A site was already created from it. The site is an official record, so the request behind it must stay Approved.
